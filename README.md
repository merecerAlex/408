# 408 随身背诵 · 使用说明

手机优先的 408 操作系统背诵工具。纯静态网页，无后端、无外部依赖、可离线。

---

## 一、怎么打开（三种方式，任选其一）

### 方式 A：双击开始（最省事）
双击本目录下的 **`start.bat`**，会自动：
1. 打开一个黑色命令行窗口（**不要关它**，关了服务就停）；
2. 自动用浏览器打开 `http://localhost:8000`。

### 方式 B：手动命令
在本目录（`D:\agent\os`）的地址栏输入 `cmd` 回车，然后：
```
python -m http.server 8000 --bind 0.0.0.0
```
浏览器打开 `http://localhost:8000`。

> 如果 `python` 不是你要的版本，用本机装了依赖的解释器：
> `C:\Users\yhf\AppData\Local\Programs\Python\Python311\python.exe -m http.server 8000 --bind 0.0.0.0`

### 方式 C：用 Node.js
```
npx serve .
```

### ⚠️ 三个必看提示
1. **必须走 http 服务**：直接双击 `index.html`（`file://`）浏览器会禁止读取 JSON，页面会显示"数据加载失败"。这是浏览器的安全限制，不是程序坏了。
   **→ 不想开服务，就用单文件版 `standalone.html`（双击即开，见「零、手机一键打开」）。**
2. **端口被占用**：如果报 `OSError: [Errno 10048] only one usage of each socket address`，说明 8000 端口已被别的程序（或你之前开的窗口）占着。换端口即可，例如 `python -m http.server 8080`，然后访问 `http://localhost:8080`。关掉旧的黑窗口也能释放。
3. **改了代码看不到变化**：按 `Ctrl + F5` 强制刷新。如果还是旧样子，说明浏览器在用离线缓存 —— 打开 F12 → Application → Service Workers → Unregister，或在 Application → Storage 里 Clear site data。

## 零、手机一键打开（推荐 · 不用服务器）⭐

**`standalone.html` 是「单文件版」**：页面、样式、脚本、全部考点数据都打包在一个 HTML 里，双击即开，不需要 Python、不需要命令行、不联网。

| 场景 | 怎么做 |
|---|---|
| 电脑上看 | 双击 `D:\agent\os\standalone.html` |
| **手机上用** | 把 `standalone.html` 发到微信/QQ 的「文件传输助手」→ 手机点开该文件 →「用其他应用打开」→ 选浏览器（Chrome / Safari / 夸克 / UC） |
| 当成 App | 手机浏览器打开后 → 菜单 →「添加到主屏幕」，以后点图标即用 |
| 完全离线 | 单文件版本身就是离线的，飞行模式也能背 |

> 微信内置浏览器有时会提示「不支持打开」，选「在浏览器中打开」就行。
> 单文件版的截图与自动验收见 `_preview/10-standalone-mobile.png` 等。

### 🔁 内容更新后必须重新打包（写死流程）
```
内容节点更新 data/knowledge.json 或 data/_parts/*.json
        ↓
在 D:\agent\os 下运行： node build_standalone.js
        ↓
把新生成的 standalone.html 重新发给主人（微信/QQ）
```
> 不重新打包，主人手里的单文件版就还是旧内容。构建脚本会自动发现 `data/_parts` 下**所有** json（不写死文件名），合并后打印：去重数、id 冲突清单、各章条数。

## 二、手机上用

1. 手机和电脑连**同一个 WiFi**；
2. 在电脑上运行上面的启动方式，命令行窗口会列出本机地址，例如：
   ```
   http://10.208.165.76:8000
   ```
   也可以用 `ipconfig` 查 IPv4 地址；
3. 手机浏览器输入这个地址即可打开。

### 添加到手机主屏幕（当 App 用）
- **Android Chrome**：打开后点右上角 ⋮ → 「安装应用」/「添加到主屏幕」；
- **iPhone Safari**：点分享按钮 → 「添加到主屏幕」。

> 注意：添加到主屏幕需要手机和电脑连**同一个局域网**才能联网加载；如需真正离线使用，看下面「三、离线」。
> 若手机打不开，先在电脑上检查 Windows 防火墙是否拦截了 8000 端口的入站连接（控制面板 → Windows Defender 防火墙 → 高级设置 → 入站规则）。

## 三、离线使用（可选）

页面注册了 Service Worker，首次通过 http 打开后，核心文件（页面、样式、脚本、考点数据）会缓存在浏览器里。之后即使服务关了，只要还能打开一次页面缓存，就能离线抽背。

## 四、怎么加 / 改考点（数据与前端分离）

**知识点只存在于 `data/` 下的 JSON 里，前端代码不含任何知识内容。**

### 4.1 三个数据来源（前端与构建脚本都会自动合并）

| 文件 | 作用 | 谁维护 |
|---|---|---|
| `data/knowledge.json` | 基线考点（MVP 示例 14 条，`status: draft`） | 开发节点 |
| `data/_parts/*.json` | **内容节点产出的分片**，结构与 knowledge.json 的 items 一致 | 知识点节点（持续增长） |
| `data/chapters.json` | 可选的手写目录（**已不再必需**） | 一般不用管 |

- **目录不用手工维护**：章 → 节 → 考点由每条数据的 `chapter` / `section` / `id` **自动聚合**（章按「第N章」排序，节按「x.y」排序，考点按 id 尾号排序）。新增一个从没出现过的章，刷新页面就会出现。
- **分片自动发现**：构建脚本扫描 `data/_parts/` 下**所有** `*.json`，不写死文件名；新分片丢进去 → 重跑一次构建即可。
- **合并规则**：按 `id` 去重；同 id 时 `status: "final"` 覆盖 `"draft"`；同级则后加载的覆盖先加载的。冲突会在构建日志里列出。

### 4.2 单条数据的字段
```json
{
  "id": "os-ch2-2.4-006",
  "chapter": "第2章 进程与线程",
  "section": "2.4 死锁",
  "topic": "死锁的四个必要条件",
  "level": "l1",
  "title": "死锁的四个必要条件",
  "answer": "……（背面的答案正文）",
  "keywords": ["互斥", "请求并保持", "不可剥夺", "循环等待"],
  "source": "王道2027版 第2章 2.4 死锁",
  "status": "final"
}
```
- `level` 三档：`l1` 🔴必背原话 / `l2` 🔵核心理解 / `l3` ⚪拓展了解（**必填，只能是这三个值**）；
- `status`：`draft` 草稿待替换 / `final` 已定稿（**final 会覆盖同 id 的 draft**）；
- 可选：`pending_source: true`（页码待核）、`boundary_note`（考纲边界备注）—— 只是备注，不影响渲染。

### 4.3 加完之后怎么验证（三条命令）
```bat
cd /d D:\agent\os

:: 1) 数据格式自检：字段齐不齐、level 合不合法、id 有没有重复、各章条数
node tools\dev.js check

:: 2) 重新打包单文件版（内容更新后必须执行）
node build_standalone.js

:: 3) 自动验收：无头浏览器以 file:// 打开单文件版，拦截所有网络请求，检查渲染条数与三大交互
node tools\verify-standalone.js
```
> 想让页面走服务器版（能装 PWA）时，`index.html` 直接刷新即可，它也会自动读取 `_parts` 下的分片。

## 五、背诵记忆系统（会了 / 模糊 / 忘了 + 多轮复习）

抽卡页不只是翻卡片，而是会**记录学习痕迹**的复习系统。

### 5.1 怎么用
1. 打开「🎴 抽卡背诵」；
2. **先点卡片翻到背面看答案**——没看答案前三档按钮是灰的（不能瞎评）；
3. 看完了，在卡片下方点：
   - **✅ 会了** → 记为掌握，下一轮会把它排到后面；
   - **🤔 模糊** → 记为半会，下一轮重点再刷；
   - **❌ 忘了** → 记为未掌握，下一轮最优先；
4. 评完自动跳下一张；顶部 HUD 显示 `第 N 轮 · 已过 x/总数 · 会了 a · 模糊 b · 忘了 c`。

### 5.2 一轮结束会发生什么
全部过完后弹出**结算面板**，显示本轮共过多少张、会了/模糊/忘了各多少、还有多少没拿稳，给出两个选择：
- **只刷没掌握的 · 再来一轮** → 第 2 轮只装「模糊 + 忘了」的卡，专攻弱点（这就是"二刷 / 多刷"）；
- **全部重来** → 轮次清零，237 张从头再来；
- **先歇一会儿** → 关掉面板，随时可以从顶部继续。

### 5.3 掌握度进度
- 抽屉目录里每个**节**后面显示 `x/y`（该节已掌握 / 总数），全掌握会变绿；
- 列表里每个考点行也会带上次的评级（会了 / 模糊 / 忘了 / 未测）。

### 5.4 记录存在哪 / 会不会丢
- 存在浏览器的 `localStorage`，**键名 `os408.progress.v2`**（单文件版是 `os408.progress.v2.standalone`）；
- 关掉页面、刷新、重启浏览器都还在；
- ⚠️ **清空浏览器数据 / 换手机 / 换浏览器会丢**——所以提供了导出。

### 5.5 导出 / 导入（防丢）
1. 打开左侧抽屉 → 底部 **⬇️ 导出记录** → 下载 `408背诵记录-<版别>-<日期>.json`；
2. 换设备后 → **⬆️ 导入记录** → 选这个 json → **覆盖**当前记录；
3. 建议每周导出一次，存到网盘/微信文件传输助手。

### 5.6 ⚠️ 单文件版与网页版的学习记录不互通（别以为丢了）
浏览器对 `file://` 打开的页面，`localStorage` 是**按文件路径隔离**的：
- 用 `standalone.html` 双开 → 记录存在 `…v2.standalone`，且跟这个文件的位置绑定；
- 用 `http://localhost` 打开 → 记录存在 `…v2`；
- **两份记录互相看不见**（应用里已自动分键，不会互相覆盖）。
→ 想共用就用「导出 → 导入」搬一次；手机上主要用单文件版，就只维护单文件版那一份。

## 六、章节考向与分值（🔥 徽章）

- 数据来源：`data/exam_trend.json`（由知识点节点产出，5 章 23 节）；
- 显示位置：列表里**每个章的标题行**、抽卡**卡片正反面**、抽屉里的**每一节**；
- 文案只显示「🔥 高频 · 选择题 2 分 × 4~6 …」这类**区间**；更详细的历年出现情况、重点、依据都在徽章的 `title` 里（电脑悬停 / 手机长按可见）；
- 手机上列表徽章只留「🔥 高频」，避免被截成省略号；
- **该文件里没有的章/节，什么都不会显示**，也不会报错——想加就在 json 里补一节；
- ⚠️ 该文件已注明：**所有分值都是区间估计，不是官方分值**，只用于安排复习优先级。

## 七、PWA（装到手机主屏）

前提：必须用 `http://`（服务器版）打开，`file://` 无法注册 Service Worker。

- `manifest.json` 完整：`name / short_name / start_url / display:standalone / theme_color / background_color` + 192/512/maskable 图标；
- `sw.js`：**缓存版本 `os408-v3`**（本次新增 `data/exam_trend.json` 进预缓存，所以版本号从 v2 提到 v3；老用户刷新一次即自动更新并清理旧缓存）；
- 安装：Android Chrome 菜单 →「安装应用」；iPhone Safari → 分享 →「添加到主屏幕」。

**改了前端文件后要不要动缓存版本？**
- 只改 `data/*.json`（考点内容）→ **不用**改，数据走的是「网络优先」，刷新即最新；
- 改了 `index.html` / `style.css` / `app.js` / 预缓存清单 → **要**把 `sw.js` 里的 `CACHE_VERSION` 从 `os408-v3` 递增一档（v4、v5…），否则老用户可能一直看到旧界面。

## 八、文件说明

| 文件 | 作用 |
|---|---|
| **`standalone.html`** | **单文件版（发手机用）**：样式 + 脚本 + 全部数据内联，双击即开 |
| `build_standalone.js` | 由源文件生成 standalone.html（幂等，可重复执行；产物不许手改） |
| `index.html` | 服务器版页面骨架（不含知识内容） |
| `style.css` | 样式（Mobile-First 响应式 + 深/浅主题 + 低端机翻转降级） |
| `app.js` | 逻辑：读取数据（内联优先 / 否则 fetch）、渲染、搜索、抽卡、记忆系统、考向徽章 |
| `data/knowledge.json` | 基线考点数据 |
| `data/_parts/*.json` | 内容节点的考点分片（自动合并） |
| `data/exam_trend.json` | 章节考向与分值（可选，缺失则无徽章） |
| `data/chapters.json` | 可选手写目录（缺省时自动聚合；顺序会自动按「第N章」重排） |
| `manifest.json` / `sw.js` | PWA 清单与 Service Worker（服务器版用，`CACHE_VERSION=os408-v3`） |
| `icons/` / `icon.svg` | 图标（`node tools\dev.js icons` 可重新生成 PNG） |
| `tools/serve.js` | 零依赖静态服务器（`node tools\serve.js 8002`，不需要 Python） |
| `tools/qa.js` | 服务器版全量验收 + 截图（375 手机 / 1280 桌面） |
| `tools/verify-memory.js` | 记忆系统 + 考向徽章 + 对比度验收（`--standalone` 验单文件版） |
| `tools/verify-standalone.js` | 单文件版离线验收（拦截全部网络请求） |
| `start.bat` | 一键启动（Python 绝对路径版） |
| `_preview/` | 自检截图（`verify-*.png`）与临时文件（不影响使用） |

### 8.1 一次性跑完全部验收
```bat
cd /d D:\agent\os
node tools\serve.js 8002          :: 另开一个窗口，保持不关
node tools\verify-memory.js       :: 记忆系统（网页版）      → 22 项
node tools\verify-memory.js --standalone   :: 记忆系统（单文件版）→ 22 项
node tools\verify-standalone.js   :: 单文件版离线可用
node tools\qa.js http://127.0.0.1:8002     :: 整体功能回归
```

> 开发纪律：本目录只保留 `index.html`、`style.css`、`app.js` 三个前端文件，**不允许出现 v2 / new / final 之类的版本副本**，所有改动都在原文件上增量修改。
> 数据纪律：知识点正文**只**存在于 `data/` 下的 JSON；`index.html` / `app.js` 里只有界面文案。
